# Telegram Audio Info Bot

Минимальный Telegram-бот, который:
- принимает `voice` и `audio` сообщения;
- сразу конвертирует их в `.wav` и сохраняет в `bot/storage/<chat_id>/`;
- делает dummy-анализ аудио и отвечает метаданными:
  - длительность;
  - sample rate;
  - число каналов;
  - битрейт (если доступен);
  - MIME/тип;
  - размер файла.

## Быстрый старт
### Вариант 1: Docker (рекомендуется для 24/7)

1. Перейти в папку бота:
```bash
cd bot
```

2. Создать `.env` с токеном:
```bash
cp .env.example .env
```
После этого открой `.env` и вставь реальный токен в `TELEGRAM_BOT_TOKEN=...`.

3. Собрать и запустить контейнер:
```bash
docker compose up -d --build
```

4. Проверить логи:
```bash
docker compose logs -f
```

5. Остановить:
```bash
docker compose down
```

Контейнер запускается с `restart: unless-stopped`, поэтому при перезагрузке сервера бот поднимется автоматически (если Docker daemon стартует на хосте).

### Вариант 2: локальный запуск без Docker

1. Перейти в папку бота:
```bash
cd bot
```

2. Установить зависимости:
```bash
python3 -m pip install -r requirements.txt
```

3. Убедиться, что установлен `ffmpeg`:
```bash
ffmpeg -version
```

4. Указать токен бота:
```bash
export TELEGRAM_BOT_TOKEN="<ТВОЙ_ТОКЕН>"
```

5. Запустить:
```bash
python3 bot.py
```

## Поведение

- На `/start` и `/help` бот отправляет подсказку.
- На `voice` или `audio` бот конвертирует в WAV, сохраняет файл и возвращает информацию.
- На другие типы сообщений просит отправить аудио.

## Примечание про группы

Если хочешь, чтобы бот видел все сообщения в группах, проверь настройки privacy mode у BotFather (обычно нужно отключить для полного сбора сообщений).
